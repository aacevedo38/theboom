# 🧠 Mapa Mental Interactivo de Inteligencia Artificial

[![Deploy to GitHub Pages](https://github.com/tuusuario/mapa-mental-ia/actions/workflows/deploy.yml/badge.svg)](https://github.com/tuusuario/mapa-mental-ia/actions/workflows/deploy.yml)
[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-blue?logo=github)](https://tuusuario.github.io/mapa-mental-ia)

Una aplicación web interactiva que presenta los conceptos fundamentales de la Inteligencia Artificial de manera visual y educativa.

## 🌐 **Demo en Vivo**

**🔗 URL:** [https://tuusuario.github.io/mapa-mental-ia](https://tuusuario.github.io/mapa-mental-ia)

## ✨ Características

- **Mapa Mental Visual**: Estructura jerárquica clara de los conceptos de IA
- **Interactividad Completa**: Haz clic en cualquier nodo para obtener información detallada
- **Diseño Responsivo**: Funciona perfectamente en dispositivos móviles y de escritorio
- **Animaciones Suaves**: Efectos visuales atractivos y profesionales
- **Controles de Zoom**: Explora el mapa mental con controles de zoom intuitivos
- **Panel de Información**: Información detallada sobre cada concepto de IA

## 🚀 **Despliegue Rápido**

### **Opción 1: GitHub Pages (Recomendado)**
1. Haz fork de este repositorio
2. Ve a Settings > Pages
3. Selecciona "Deploy from a branch"
4. Elige la rama `main`
5. ¡Tu mapa mental estará disponible en `https://tuusuario.github.io/mapa-mental-ia`!

### **Opción 2: Local**
1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. ¡Listo para usar!

## 📚 Conceptos Incluidos

### 🤖 Machine Learning
- **Supervisado**: Clasificación y regresión
- **No Supervisado**: Clustering y reducción dimensional
- **Refuerzo**: Aprendizaje por experiencia

### 🧠 Deep Learning
- **CNN**: Redes neuronales convolucionales
- **RNN**: Redes neuronales recurrentes
- **Transformers**: Arquitectura de atención

### 💬 Procesamiento de Lenguaje Natural (NLP)
- **Análisis de Texto**: Sentiment analysis, NER
- **Traducción**: Traducción automática
- **Chatbots**: Asistentes conversacionales

### 👁️ Computer Vision
- **Detección de Objetos**: Identificación y localización
- **Segmentación**: División de imágenes en regiones
- **Reconocimiento Facial**: Identificación de personas

### 🤖 Robótica
- **Vehículos Autónomos**: Coches y drones autónomos
- **Robots Industriales**: Automatización de fábricas
- **Robots Humanoides**: Robots con forma humana

### ⚖️ Ética y Sociedad
- **Sesgos**: Discriminación algorítmica
- **Privacidad**: Protección de datos
- **Empleo**: Automatización del trabajo

## 🔧 Personalización

### Agregar Nuevos Conceptos
1. Edita el archivo `script.js`
2. Agrega nuevas entradas al objeto `conceptInfo`
3. Actualiza el HTML con nuevos nodos
4. Ajusta el CSS según sea necesario

### Cambiar Colores y Estilos
1. Modifica las variables CSS en `styles.css`
2. Ajusta gradientes y sombras
3. Personaliza animaciones y transiciones
